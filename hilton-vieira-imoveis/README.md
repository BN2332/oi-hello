# Hilton Vieira — Imóveis em Monte Sião

Site demonstrativo responsivo para apresentação comercial ao corretor Hilton Vieira.

## Arquivos
- index.html: estrutura e conteúdo.
- styles.css: identidade visual responsiva.
- script.js: filtros demonstrativos, favoritos, menu mobile e WhatsApp.

## Antes de publicar
1. Substitua as imagens ilustrativas por fotos autorizadas dos imóveis e do corretor.
2. Atualize imóveis, preços, metragem, bairros e descrições com informações reais.
3. Preencha WHATSAPP_NUMBER em script.js com o número comercial, no formato internacional e somente números.
4. Confirme autorização para uso do nome, marca e dados de contato.
5. Configure domínio e hospedagem.

**Aviso:** imóveis, valores e fotografias são ilustrativos. Este projeto é uma demonstração e não representa ofertas reais.
